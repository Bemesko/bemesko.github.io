# Substack brand kit

Matches the portfolio's chart identity. Captain DevOps is the blog's and the portfolio's identity; professional profiles (LinkedIn, GitHub) use **Bemesko**.

Regenerate the images with `python scripts/make-substack-kit.py <font-work-dir>`.

## Images

| File                                   | Use in Substack                                                        |
| -------------------------------------- | ---------------------------------------------------------------------- |
| `logo.png` (1024×1024)                 | Settings → Basics → Publication logo                                   |
| `wordmark.png` (1700×360, transparent) | Settings → Basics → Wordmark (shown in the header instead of the name) |
| `cover.png` (1200×630)                 | Settings → Basics → Cover photo / social image                         |

## Colours

| Role                               | Hex       |
| ---------------------------------- | --------- |
| Accent (buttons, links)            | `#1F56A8` |
| Background, if the theme allows it | `#F1EADB` |
| Text / dark                        | `#14233A` |

## Fonts

Substack only offers its own font list. Pick the closest:

- Headings: a geometric sans (closest to Space Grotesk).
- Body: a classic serif (closest to Source Serif 4).
